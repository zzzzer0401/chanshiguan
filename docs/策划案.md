# 《别吵，在刷好感呢！》策划完善案（Demo v0.1）

> 创意来源：公众号「思考千事万物」文章[《别吵，在刷好感呢！｜ 一款把“铲屎官”逼疯的8×8硬核策略小游戏》](https://mp.weixin.qq.com/s/dlx8WqC6eNuw7Ac6FInsUg)。本文在其核心设定上补充数值、关卡、引导与留存设计。

> 一句话：**软萌狗狗 × 硬核算账**。每天 10 点体力，走格子、喂零食、摸摸头，还必须在体力耗尽前回到另一座小屋——算错一步，三只狗狗一起翻白眼：“连家都回不去？”

---

## 1. 产品定位

| 项目 | 说明 |
|---|---|
| 平台 | 微信小游戏（竖屏，单手操作，Canvas 2D） |
| 品类 | 回合制路径规划解谜 + 轻养成 |
| 目标用户 | 18–35 岁，喜欢萌宠、喜欢“算一算”的轻度解谜玩家；碎片时间 2–5 分钟一局 |
| 核心体验 | 反差萌：画面软萌可爱，规则冷酷精确；每一步都是成本收益计算 |
| 情绪曲线 | 规划（紧张）→ 刚好回家（爽）→ 狗狗开心（治愈）/ 算错被吐槽（好笑、想再来） |

---

## 2. 核心规则（已数值化，Demo 已实现）

### 2.1 一天的流程
1. 每天从一座小屋出发，**目标是另一座小屋**（红顶 ↔ 蓝顶，每天交替，路线每天都在变）。
2. 每天体力 **10 点**，当天用完就没有，不能回复、不能带到明天。
3. 回到目标小屋时当天自动结算。
4. 夜里：狗狗的好感按性格结算 → 零食刷新 → 柴犬换心情 → 会散步的狗挪窝 → 第二天。

### 2.2 行动成本
| 行动 | 体力 | 条件 |
|---|---|---|
| 移动 1 格（上下左右） | 1 | 不能穿过灌木、栅栏、花坛、狗狗 |
| 喂食 | 2 | 背包里要有零食（棋盘上捡，最多带 3 个，每天刷新） |
| 摸摸 | 2 | — |

* 同一只狗、同一天、同一种互动**只有第一次有效**（防止站桩刷分，逼玩家跑图、分配体力）。
* 每次互动前，按钮上会**明牌显示收益**（例：`+4❤`、`+0 哼！`），硬核但不坑人。

### 2.3 回巢铁律（核心失败条件）
* 系统实时计算“回家最短距离”。一旦 **剩余体力 < 回家距离**，立刻判定“回巢失败”：
  * 当天刷到的好感**全部清零**（回滚到当天早上）；
  * 三只狗狗同时翻白眼吐槽（“连家都回不去？”）；
  * 当天作废，第二天从原来的小屋重新出发；边牧会因为“被冷落”多掉好感。
* 补救：每关有 1 次“重来今天”（正式版：看激励视频 / 分享获得）。

### 2.4 胜负
* **胜利**：某天回到家的那一刻，所有狗狗好感都 ≥ 目标值。
* **失败**：天数用完还没达标。
* **星级**：★ 通关　★ 没有回巢失败　★ 在“标准天数”内通关。

## 3. 三只狗狗（玩法差异化）

| | 橘子（柴犬） | 芝麻（边牧） | 棉花糖（贵宾犬） |
|---|---|---|---|
| 性格 | 傲娇 | 高冷 | 洁癖 |
| 互动范围 | 2 格内（曼哈顿距离） | 2 格内 | **只认上下左右紧挨着** |
| 喂食 / 摸摸 | +4 / +3（仅限心情对上） | +2 / +3 | +4 / +3 |
| 专属规则 | 每天心情不同：**想吃 / 想摸 / 哼（全拒）**；做错 = +0。后期出现“**？**”心情：要走到它身边才知道，考验带不带零食的容错规划 | 好感**每晚 -1**；当天没理它则 **-2**。必须持续维系，且“达标”要卡在回家那一刻 | 身上沾了**泥**就拒绝一切互动；踩水洼可洗干净。泥地常是捷径——走不走？ |
| 吐槽风格 | “就这？还想当我的铲屎官？” | “10点体力都算不清？我都会算。” | “在外面过夜？脏死了！” |

设计意图：柴犬考验**信息与容错**，边牧考验**长期节奏**，贵宾考验**站位与路径**，三者叠加形成“走格子 + 资源管理 + 养成目标”的三重闭环。

## 4. 棋盘元素

| 元素 | 效果 | 设计用途 |
|---|---|---|
| 草地 | 普通格 | — |
| 灌木 / 栅栏 / 花坛 | 不可通行 | 制造绕路成本 |
| 泥坑 | 可走，踩到后“身上有泥” | 捷径 vs 贵宾洁癖的取舍 |
| 水洼 | 可走，洗掉泥 | 给“先脏后洗”留解法 |
| 骨头零食 | 踩上去捡起，背包上限 3，每天刷新 | 喂食的前置资源，绕不绕路去拿 |
| 散步路线（第二章） | 某只狗每晚沿固定路线挪窝，提前显示明天位置 | 让“明天的路线”成为今天的规划变量 |

## 5. 上手难度设计（降低门槛，但不降低硬核）

1. **一关只教一件事**：1-1 走路回家 → 1-2 柴犬心情与零食 → 1-3 边牧衰减 → 1-4 贵宾与泥坑，第二章才全部叠加。
2. **开局图文引导**：每个新机制第一次出现时，由狗狗本狗用对话框讲规则（可跳过）。
3. **明牌可视化**（新手辅助，默认开启）：
   * 棋盘上**绿点 = 去了还能回家，红格 = 去了就回不了家**；
   * 状态栏常驻“回家需 X⚡”；
   * 选中狗狗时高亮它的**互动范围**；
   * 互动按钮直接显示收益（+4❤ / +0 哼！）。
4. **防误触**：点红格 / 会导致回不了家的互动，需要**二次确认**。
5. **撤销**：每关 3 次（教学关无限）；**提示**：自动算出“今天的最优路线”并画在棋盘上（每关 2 次）。
6. **硬核模式**（设置里开）：关闭红绿格与二次确认，通关额外获得🏅——给高玩留出炫耀空间。

---

## 6. 可玩性 / 深度

* **最优解挑战**：每关有“标准天数”，三星需要零失误；提示系统用的是真实求解器，玩家能感到“确实还有更优解”。
* **双屋交替**：同一张图每天方向相反，同一关内路线规划不重复。
* **信息博弈**：柴犬“？”心情 → 带 1 个零食当保险，还是赌它想要摸摸？
* **跨天规划**：柴犬“哼”的那天去囤零食；边牧掉好感要提前“储值”；散步狗明天的位置会挡路或靠近。
* **每日挑战**：按日期生成的随机棋盘（求解器校验可解），全服同题，比拼天数。

## 7. 用户粘性（留存系统）

| 系统 | 机制 | Demo |
|---|---|---|
| 关卡星级 | 3 星评价，星星解锁后续章节 | ✅ |
| 狗狗档案 / 羁绊 | 通关获得星星 → 对应狗狗羁绊升级 → 解锁专属语录（正式版：装扮、相册、动态表情） | ✅ 语录 |
| 每日挑战 + 连续打卡 | 每天一题，连续天数🔥，断签有“补签卡” | ✅（打卡计数） |
| 好友排行 | 每日挑战用天数/剩余体力排名（微信开放数据域） | 正式版 |
| 分享吐槽卡 | 失败时生成“我家柴犬说我连家都回不去…”卡片，好友点开直达同一关 | ✅ 接口（微信内调用分享） |
| 订阅提醒 | “狗狗想你了”每日挑战提醒（订阅消息） | 正式版 |
| 回流钩子 | 边牧“想你”的离线好感衰减只做表现、不做惩罚，避免劝退 | 正式版 |

**不做体力限制玩法次数**：核心玩法本身就是“体力”，再在系统层卡次数会混淆概念、劝退解谜用户。

## 8. 商业化（轻度，不破坏硬核）
* 激励视频：重来今天、额外提示、额外撤销。
* 外观付费：狗狗装扮、小屋皮肤、铲屎官服装（纯外观）。
* 分享裂变：吐槽卡、每日挑战战绩卡。

## 9. 关卡规划（Demo 8 关）

| 关卡 | 名称 | 新内容 | 狗狗（目标好感） | 标准天数 / 上限 |
|---|---|---|---|---|
| 1-1 | 回家的路 | 体力、回巢、摸摸 | 柴犬 3 | 1 / 2 |
| 1-2 | 傲娇橘子 | 心情、零食、喂食 | 柴犬 10 | 4 / 5 |
| 1-3 | 高冷芝麻 | 好感衰减、多狗分配 | 柴犬 6、边牧 7 | 3 / 4 |
| 1-4 | 洁癖棉花糖 | 紧挨互动、泥坑、水洼、留零食 | 贵宾 10 | 2 / 3 |
| 2-1 | 三只都要宠 | 三狗同场 | 6 / 5 / 6 | 5 / 6 |
| 2-2 | 芝麻去散步 | 散步路线 | 5 / 6 / 6 | 5 / 6 |
| 2-3 | 猜不透的橘子 | “？”心情 | 7 / 5 / 6 | 5 / 6 |
| 2-4 | 终极铲屎官 | 综合考验 | 7 / 7 / 8 | 6 / 7 |

**数值验证**：标准天数 = 求解器算出的**理论最少天数**（按天广度搜索所有“当天回家结局”，带支配剪枝），每关都经过“按提示一路走 → 三星通关”的自动化回归。上限 = 标准 + 1，给一次回巢失败的容错。第二章需第一章累计 5 星解锁。

正式版规划：6 章 × 12 关 + 每日挑战 + 季节活动关（雪地：每步 1.5 体力；雨天：全图泥坑）。

## 10. 关键数据指标
* 新手漏斗：1-1 → 1-4 完成率（目标 > 70%）
* 回巢失败率：单关 > 40% 说明数值过紧
* 提示使用率、撤销使用率（判断关卡是否卡人）
* 次留 / 7 留、每日挑战参与率、分享回流率

## 11. 技术说明（Demo）
* 纯 Canvas 2D 实现，一套代码同时跑在**微信小游戏**和**浏览器**（`js/platform.js` 做适配）。
* 规则层 `js/rules.js` 与渲染完全分离，内置求解器（提示系统 + 关卡/每日挑战可解性校验）。
* 美术为 AI 生成后切图，素材在 `images/`，原图在 `art_src/`（已在打包配置中忽略）。
